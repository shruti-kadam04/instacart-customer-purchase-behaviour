# instacart-customer-purchase-behaviour
Data Science Internship Project focused on analyzing Instacart customer purchase behaviour, reorder patterns, popular products, departments, and ordering trends using Python, Pandas, NumPy, Matplotlib, and Seaborn.

Objectives:
1.Analyze customer purchase and reorder behaviour
2.Identify the most frequently ordered products
3.Examine popular product departments
4.Study ordering trends by day of week and hour of day
5.Analyze correlations between key numerical variables
6.Calculate core metrics: total orders, total customers, reorder percentage

Dataset:
This project uses the Instacart Market Basket Analysis dataset, available on Kaggle:
https://www.kaggle.com/c/instacart-market-basket-analysis/data
Note: orders.csv and order_products__prior.csv are not included in this repository due to GitHub's file size limit. Please download them from the Kaggle link above and place them in the project directory before running the script.

Technologies Used:
1.Python
2.Pandas
3.NumPy
4.Matplotlib
5.Seaborn
